# SmartPockets

Community stokvel savings ("pockets"), automatic roundups, a cashflow co-pilot,
an investment optimiser and short money lessons. A React + Vite + Tailwind app
that runs entirely on its own: no hosted backend, no API keys.

## Run it in VS Code

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173), create an account, and
the app seeds some sample data on first login.

**Testing on your phone:** the dev server is exposed on your network. With your
phone on the same Wi-Fi, open the "Network" URL Vite prints.

Other scripts: `npm run build` (production build into `dist/`), `npm run preview`,
`npm run lint`.

## Where the data lives

All data (accounts, pockets, transactions, goals, lessons) is stored in your
browser's localStorage by `src/api/client.js`. That file is the whole "backend":

- `api.auth`: register, log in, log out, reset password
- `api.entities.*`: create / filter / update / delete / aggregate for each table
- `api.functions.invoke(...)`: the cashflow forecast, coaching text and portfolio optimiser

To wipe everything and start fresh, open the browser console and run
`smartpocketsReset()`.

## Limits of local mode

- Data stays on one device and one browser. There is no sync between phones.
- Accounts are local. Pocket "members" on other phones can't see your pocket.
  Passwords are hashed, but with no server this is for development and demos,
  not for protecting real money or real personal data.
- Password reset happens on the device (no email is sent).
- The co-pilot's advice is generated by simple rules in `src/lib/narrative.js`
  rather than an AI model.

## Moving to a real backend later

Every page talks to `api` from `src/api/client.js` and nothing else. To add real
accounts and shared pockets, keep the same `api` shape and implement it with
Supabase, Firebase or your own server. No page needs to change.

## Layout

```
src/api/client.js     local backend (auth, entities, functions)
src/lib/              forecast, optimiser, narrative, lesson content, helpers
src/pages/            Home, Pockets, Savings, Copilot, Invest, Learn, auth pages
src/components/       UI building blocks (shadcn/ui in components/ui)
```
